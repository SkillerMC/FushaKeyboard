فصحى 3.0 — فقاعة عائمة

بدل كيبورد مخصص، التطبيق الآن فقاعة صغيرة تطلع فوق أي تطبيق ثاني (Discord مثلاً).
تضغطها وهي تاخذ النص من الحقل المفعّل حاليًا، تحوّله لعربية فصحى صحيحة، وترجعه
بنفس المكان تلقائيًا — بدون تبديل كيبورد وبدون نسخ/لصق يدوي.

كيف تشتغل:
1. افتح التطبيق، اضغط "منح صلاحية النافذة العائمة" ووافق.
2. اضغط "تفعيل خدمة الوصول (Accessibility)"، ودوّر على "فصحى" بالقائمة وفعّله.
3. (اختياري) أدخل مفتاح Anthropic API واحفظه، عشان التحويل يصير بالذكاء الاصطناعي
   الحقيقي بدل القاموس المحلي البسيط.
4. اضغط "تشغيل الفقاعة" — بتطلع فقاعة صغيرة مكتوب عليها "ف"، تقدر تسحبها لأي مكان
   بالشاشة.
5. أي وقت تكون كاتب بحقل نص بأي تطبيق، اضغط الفقاعة وبتصحح آخر نص بذاك الحقل.

بدون مفتاح API:
تستخدم قاموس استبدال محلي بسيط (كلمات عامية شائعة)، وليس تصحيحًا نحويًا حقيقيًا.

ملاحظة أمان: خدمة الوصول (Accessibility) لا تعمل شي إلا عند ضغط الفقاعة يدويًا،
ولا ترسل أي نص لأي مكان غير Anthropic API مباشرة (ولا شي إذا ما فيه مفتاح API).
المفتاح يُحفظ محليًا على جهازك فقط.

البناء: افتح المشروع في Android Studio ثم Build > Build APK(s)، أو ادفعه
لـ GitHub (فيه GitHub Actions مُعد مسبقًا يبنيه تلقائيًا).
